# 모바일 뷰 레이아웃 정리 (홈 화면)

390px 뷰포트에서 실제 확인한 결과, 문서 전체 가로 스크롤 폭이 427px로 화면보다 넓게 벌어져 있었습니다. 이 가로 넘침이 헤더 잘림·랭킹 카드 우측 잘림의 공통 원인입니다.

## 확인된 문제

1. 헤더: 로고 `VIEW KIT`이 두 줄로 접히고, 우측 유틸(지점 뱃지 / 콘텐츠 요청 / 세로모드 / 햄버거)이 한 줄에 다 들어가지 못해 햄버거 버튼이 화면 밖으로 밀림.
2. 요즘 많이 본 콘텐츠: 카드 래퍼에 `ml-5`(왼쪽 20px 밀기)가 걸려 3열 그리드 전체가 오른쪽으로 밀리며 세 번째 카드가 잘림. 숫자 오버레이는 64px 고정 크기로 모바일 카드(약 100px 폭) 대비 과하게 크고 이미지 하단을 가림.
3. 제품 그리드 NEW 뱃지: 카드 라운드(20px) 모서리에 `right-2 top-2`로 붙어 시각적으로 잘려 보임.
4. 판매 인증 플로팅 배지: `fixed bottom-5 right-5 z-40`으로 마지막 줄 카드와 겹칠 수 있음(현재 하단 여백 부족 시).
5. 좌우 여백은 섹션마다 `px-5 sm:px-10`으로 통일돼 있으나, 위 `ml-5` 때문에 실질 여백이 깨져 있음.

## 수정 내용

### 1. 헤더 (src/pages/ProductSelection.tsx)
- 로고에 `whitespace-nowrap` 적용, 모바일 폰트 `20px` → `sm:28px`로 단계화하여 줄바꿈 방지.
- 헤더 좌우 패딩을 `px-4 sm:px-10`으로, 요소 간격을 `gap-1.5 sm:gap-2`로 통일.
- 모바일에서 버튼 높이를 `h-11` → `h-9 sm:h-11`, 햄버거 `w-9 h-9 sm:w-11 sm:h-11`로 축소.
- 모바일에서는 텍스트 라벨 대신 아이콘만 노출: 콘텐츠 요청·세로모드 버튼 라벨을 `hidden sm:inline` 처리(각 컴포넌트의 segment/pill 스타일 유지, 라벨만 반응형으로 감춤).
- 지점 뱃지는 `shrink-0`, 우측 nav는 `min-w-0`로 잡아 오버플로우 방지.

### 2. 요즘 많이 본 콘텐츠 (src/components/PopularContentSlider.tsx)
- 카드 이미지 래퍼의 `ml-5` 제거 → 3열이 섹션 패딩 안에서 균등 폭·균등 간격(`gap-2.5 sm:gap-4`)으로 정렬.
- 숫자 오버레이를 반응형으로: `text-[36px] sm:text-[56px]`, 위치는 카드 안쪽(`left-1 bottom-1 sm:left-1.5 sm:bottom-1.5`)으로 이동, 스트로크 두께 `1.5px sm:2px`.
- 이미지 높이 `h-[110px] sm:h-[140px]`로 조정, 텍스트 영역 패딩 `p-2.5 sm:p-3`.
- 로딩 스켈레톤도 동일한 gap/높이 규칙에 맞춤.

### 3. 제품 카드 NEW 뱃지
- 위치를 `right-2.5 top-2.5`로 안쪽 이동, 패딩 `px-1.5 py-0.5`, 폰트 `text-[10px] sm:text-[12px]`로 축소해 모서리 잘림 방지.

### 4. 판매 인증 플로팅 배지 (src/components/SalesCertBadge.tsx)
- `z-40` → `z-50`, 위치를 `bottom-4 right-4 sm:bottom-5 sm:right-5`로 고정하고 안전영역(`env(safe-area-inset-bottom)`) 보정 추가.
- 제품 그리드 섹션 하단 패딩을 `pb-24 sm:pb-12`로 늘려 마지막 줄 카드와 겹치지 않게 함.

### 5. 반응형 여백 일관성
- 헤더 / 히어로 / 인기 콘텐츠 / 제품 그리드 모두 `px-4 sm:px-10`으로 통일.
- 카드 gap은 인기 콘텐츠·제품 그리드 모두 `gap-2.5 sm:gap-4`로 통일.

## 검증
- 390px·430px·768px 뷰포트에서 스크린샷 촬영 후 `scrollWidth === 뷰포트 폭`(가로 스크롤 없음) 확인.
- 데스크톱(1280px)·가로모드 토글 상태에서 기존 레이아웃 변화 없는지 비교.
