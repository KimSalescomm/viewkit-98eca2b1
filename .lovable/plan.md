# AI 워시타워 6개 특장점 추가

## 목표

기존 `워시타워`와 별개로 `AI 워시타워` 제품을 추가하고, AI 워시콤보와 같은 질문형 카드·탭·상세정보 구조로 6개 특장점을 제공합니다. 제품 목록과 직접 주소 모두 **SC 관리자 계정에서만** 열람할 수 있게 제한합니다.

## 구현 내용

### 1. AI 워시타워 제품 추가

- 기존 워시타워 제품과 데이터는 그대로 유지합니다.
- 별도 제품 ID와 제품명 `AI 워시타워`를 등록합니다.
- 메인 제품 선택 화면에는 SC 계정에서만 AI 워시타워 카드를 표시합니다.
- AI 워시타워 전용 제품 이미지와 카드 아이콘을 연결합니다.

### 2. 질문형 특장점 6개 구성

- LG 공식 AI 워시타워 자료를 기준으로 기능명, 설명, 영상·이미지, 시험 조건을 확인합니다.
- AI 워시콤보 카드의 표현 방식을 따라 각 카드에 다음 요소를 적용합니다.
  - 질문형 제목
  - 2줄 핵심 설명
  - 기능명 태그
  - 영상 또는 이미지
  - `핵심만 쏙` 요약
  - 필요한 경우 탭, 세부 기능 아코디언, 시험 조건 토글
- AI 워시콤보 내용을 그대로 복사하지 않고, AI 워시타워에 실제 적용되는 기능과 공식 자료만 사용합니다.
- 6개 카드의 순서와 목록 썸네일을 별도 설정해 일관된 카드 화면을 만듭니다.

### 3. SC 관리자 전용 노출

- AI 워시타워를 명시적인 `SC 전용 제품`으로 분류합니다.
- 일반 매장과 KOR 계정에서는 메인 제품 카드가 표시되지 않게 합니다.
- 일반 매장과 KOR 계정이 `/product/AI워시타워ID` 또는 특장점 주소를 직접 입력해도 열람할 수 없게 합니다.
- 관리자 제품 노출 설정 화면에서는 일반 매장에 공개할 수 있는 선택 항목으로 나타나지 않게 합니다.

### 4. 확인

- SC 계정: AI 워시타워 제품 카드, 6개 특장점, 각 상세 화면 노출 확인
- KOR 및 일반 매장: 제품 카드 비노출과 직접 주소 차단 확인
- 기존 워시타워·AI 워시콤보의 순서와 콘텐츠가 바뀌지 않는지 확인
- 모바일, 스탠바이미 세로 화면, 가로 화면에서 6개 카드 배치와 미디어 재생 확인

## 변경 예상 파일

- 제품 정보와 제품 순서
- 특장점 데이터와 카드 썸네일 설정
- SC 전용 제품 판정 및 직접 주소 접근 제한
- 관리자 제품 노출 설정의 공개 대상 필터
- AI 워시타워 제품 아이콘이 필요한 경우 제품 아이콘 구성

## 기술 세부사항

- 기존 `scOnly`는 개별 특장점용이므로, 제품 전체를 SC 전용으로 처리하는 별도 제품 ID 집합을 추가합니다.
- 제품 조회와 특장점 조회가 동일한 SC 판정을 사용하도록 해 목록 숨김과 직접 주소 차단이 일치하게 합니다.
- 새 제품은 정적 콘텐츠로 관리하여 일반 콘텐츠 수정처럼 러버블 Publish로 반영되도록 합니다.
