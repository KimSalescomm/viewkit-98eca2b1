# 버튼 위치 통합 계획

## 현재 문제
홈 화면에 버튼이 3개 영역(상단 segmented control, 우측 하단 판매 인증, 하단 콘텐츠 요청)에 흩어져 있어 위치가 산만해 보임.

## 정리 방향
- **버튼 개수는 줄이지 않고**, 위치를 통합하여 한눈에 들어오게 정리.
- **상단 영역**에 모든 보조 기능을 모아두고, 제품 카드는 깔끔하게 남김.
- 기존 기능과 터치 타겟은 그대로 유지.

## 구체적인 변경

### 1) 상단 segmented control 축소
- 현재: 지점 변경 / 모바일에서 보기 / 뷰킷 소개 / 세로모드 (4개)
- 변경:
  - **지점 변경**과 **세로모드**는 핵심이므로 그대로 노출.
  - **모바일에서 보기**와 **뷰킷 소개**는 아이콘만 보이고, 터치 시 툴팁/드롭다운으로 전체 라벨 노출.
  - 또는 “모바일에서 보기”를 지점 변경 버튼 옆에 작은 아이콘 버튼으로 이동.
- 결과: 상단은 2~3개의 버튼만 남기고, 나머지는 아이콘으로 전환.

### 2) 판매 인증 플로팅 버튼 정리
- 현재: 우측 하단에 그라데이션 팝 버튼.
- 변경:
  - 시각적으로 과하게 튀지 않도록 단색 브랜드 컬러로 변경하거나, 아이콘 중심으로 축소.
  - 모바일에서는 하단 콘텐츠 요청 버튼과 겹치지 않도록 위치를 좌측 하단 또는 상단으로 이동 고려.
  - 또는 우측 하단에 FAB 메뉴를 만들어 “판매 인증”과 “콘텐츠 요청”을 하나의 + 버튼으로 묶음.

### 3) 콘텐츠 요청 버튼 정리
- 현재: 하단 가운데에 큰 pill 버튼.
- 변경:
  - pill 버튼을 더 작은 아이콘 + 텍스트 버튼으로 축소.
  - 또는 상단 segmented control에 “요청” 아이콘을 추가하고 하단 버튼은 제거.

## 우선 적용안
- 상단: 지점 변경 / 세로모드만 라벨 노출, 모바일에서 보기/뷰킷 소개는 아이콘만.
- 하단: 콘텐츠 요청 버튼을 pill에서 아이콘 텍스트로 축소.
- 판매 인증: 단색 브랜드 버튼으로 변경하고, 모바일에서 좌측 하단으로 이동해 하단 버튼과 겹치지 않게 조정.

## 기대 효과
- 메인 화면의 시선이 제품 카드로 집중됨.
- 터치 타겟은 유지하면서 화면 공간이 정리됨.
- 핵심 기능(지점 변경, 제품 선택, 판매 인증, 콘텐츠 요청)은 그대로 사용 가능.
