# 케어 메뉴를 가로 화면에서 한 줄로

## 바뀌는 점
- 가로 화면(태블릿 가로·PC)에서는 케어 메뉴 버튼의 글자, 좌우 여백, 버튼 사이 간격을 조금씩 줄여요. 그래서 7개(분해 케어 ~ 급수부 클리닝)가 한 줄에 다 보여요.
- 세로 화면이나 좁은 화면에서는 지금 크기를 그대로 두고, 공간이 부족하면 다음 줄로 넘어가요. 옆으로 밀어서 넘기는 부분은 계속 없어요.
- 색상(밝은 레드), 사진·영상, 설명 문구는 그대로예요.

## 확인
- 1152px 가로 화면에서 7개가 한 줄에 보이는지 확인해요.
- 세로 화면에서는 지금처럼 여러 줄로 자연스럽게 보이는지 확인해요.

## 기술 세부사항
- `CareProcessSection.tsx`의 메뉴 버튼 크기를 화면 폭에 따라 다르게 지정해요. 큰 화면(`lg`)에서는 글자 13px, 좌우 여백 12px, 버튼 사이 간격 4px, 높이 36px로 줄여요.
- 메뉴 줄의 자동 줄바꿈 설정은 유지해서, 폭이 부족한 화면에서는 계속 다음 줄로 넘어가게 해요.
