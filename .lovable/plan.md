# 관리자 월별 접속 통계 기능 추가

## 목표

관리자 대시보드에서 2026년 1월부터 현재까지 월별 접속 통계를 한눈에 보고, 한 번의 다운로드로 받을 수 있도록 개선합니다. 기존처럼 기간 프리셋을 하나씩 바꿔 다운로드할 필요가 없습니다.

## 확인한 현재 상태

- `page_views` 테이블의 실제 기록은 **2026-06-08**부터 시작됩니다. 따라서 1~5월은 0으로 표시됩니다.
- 현재 Admin > "지점별 접속통계" 탭에는 오늘/7일/14일/30일/전체 프리셋과 해당 기간의 지점별 집계만 있고, 월별 집계 UI는 없습니다.
- `src/pages/Admin.tsx`에 `fetchAllPageViews`, `aggregateVisits`, `handleExportAll` 등이 이미 구현돼 있어 전체 기간 데이터를 가져와 집계하는 로직을 재사용할 수 있습니다.

## 구현 내용

### 1. 월별 집계 데이터 생성

- `fetchAllPageViews(SITE_OPEN_ISO)`로 전체 `page_views`를 가져옵니다(기존 페이지네이션 로직 재사용).
- KST 기준 월(`YYYY-MM`)로 그룹화합니다.
- 각 월마다 아래 지표를 계산합니다.
  - `페이지뷰`: 해당 월의 전체 행 수
  - `방문(세션)`: 해당 월의 고유 `session_id` 수
  - `방문(보정)`: 지점별·일별 고유 세션 수를 `DAILY_VISIT_CAP`(20)으로 제한한 합계
  - `활성 지점`: 해당 월에 기록이 있는 고유 `store_id` 수
- 2026년 1월부터 현재 월까지 데이터가 없는 달은 0으로 채워 표시합니다.

### 2. 관리자 화면 UI

- "지점별 접속통계" 탭 하단에 "월별 접속 통계" 카드를 추가합니다.
- 테이블 컬럼: 월, 페이지뷰, 방문(세션), 방문(보정), 활성 지점
- "월별 통계 CSV 다운로드" 버튼을 추가합니다.

### 3. CSV 다운로드

- 다운로드 파일명: `monthly-visit-stats_YYYYMMDD_HHmm.csv`
- BOM(`\uFEFF`) 포함, Excel 한글 깨짐 대응
- 내용: 월별 요약 테이블 + 생성 시각

### 4. 기존 "전체 내보내기" 개선(선택)

- `handleExportAll` 결과 시트에 `[5] 월별 접속 요약` 시트(또는 섹션)를 추가하여, 한 번의 다운로드에 지점별 통계와 월별 통계가 모두 포함되도록 합니다.

## 예상 결과

- 관리자는 /admin 접속 후 "지점별 접속통계" 탭에서 2026년 1월~현재 월별 통계를 바로 확인할 수 있습니다.
- "월별 통계 CSV 다운로드" 버튼 클릭 시 하나의 파일로 모든 월의 요약이 다운로드됩니다.
- 1~5월은 데이터가 없으므로 0으로 표시됩니다.
