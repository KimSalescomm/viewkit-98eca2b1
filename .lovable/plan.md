# 인기콘텐츠 영역 + 고정 캔버스

## 목표
1. 홈(제품 선택) 화면을 스크롤 없이 한 화면에 들어오는 고정 캔버스로 만든다.
2. 헤더 아래에 조회수 기준 인기콘텐츠 슬라이드(3~5개)를 추가한다.
3. 제품 카드는 크기를 줄여 남는 공간을 확보한다.

## 1. 인기콘텐츠 데이터 (조회수 자동 집계)

이미 `page_views` 테이블에 경로별 방문 기록이 쌓이고 있다(`/product/tv/feature/1` 형태, 지점 계정만 기록, SC/KOR 제외).

- 백엔드에 집계 함수를 추가해 상위 특장점 경로와 조회수를 한 번의 호출로 받아온다. (수천 행을 클라이언트로 내려받지 않도록 서버 집계)
  - 입력: 기간(기본 최근 30일), 개수(기본 5)
  - 출력: `path`, `views`
  - `/product/{productId}/feature/{featureId}` 패턴만 대상으로 하고, 제품 목록 페이지·홈은 제외
- 프런트에서 경로를 `products.ts` / `features.ts` 데이터와 매칭해 제품명·특장점 제목·썸네일을 붙인다.
- 현재 지점에서 볼 수 없는 제품(비노출·대외비)의 항목은 필터링해 제외한다.
- 집계 결과가 없거나 3개 미만이면 인기콘텐츠 영역 자체를 렌더링하지 않는다(레이아웃 흔들림 방지).
- 결과는 짧게 캐싱(수 분)하고, 진입 시마다 최신 값으로 갱신한다.

## 2. 인기콘텐츠 슬라이드 UI

- 위치: 헤더("어떤 제품부터 보시겠어요?") 아래, 제품 카드 그리드 위.
- 형태: 가로 슬라이드. 세로 터치 디스플레이 기준 한 화면에 1.2~1.5장이 보이도록 하고 좌우 화살표 + 스와이프/드래그 지원, 스냅 정렬.
- 카드 구성: 썸네일 + 제품명 배지 + 특장점 제목 + 순위 표시(1~5). 조회수 숫자는 노출하지 않는다.
- 클릭 시 해당 특장점 상세로 이동하며 기존 분석 이벤트를 함께 기록한다.
- 섹션 타이틀: "요즘 많이 본 콘텐츠".

## 3. 고정 캔버스 + 제품 카드 축소

- 홈 컨테이너를 `100dvh` 고정 높이 + `overflow-hidden`으로 잡고, 상단 컨트롤 / 헤더 / 인기콘텐츠 / 제품 그리드를 세로 flex로 배분한다.
- 제품 그리드는 남는 영역을 채우도록 하고, 카드 축소를 적용:
  - 이미지 비율 축소, 패딩·라운드·아이콘 크기 축소, 설명 문구 줄 수 제한
  - 세로 디스플레이에서 2열, 넓은 화면에서 3열로 카드 수 대비 높이를 줄인다
- 카드가 화면보다 많을 때는 전체 페이지 스크롤 대신 그리드 영역 내부에서만 스크롤되게 처리한다(외곽 레이아웃 고정 유지).
- 가로모드(`html[data-orientation="landscape"]`) 오버라이드도 동일 규칙으로 맞춘다.

## 기술 메모

- 변경 파일: `src/pages/ProductSelection.tsx`(레이아웃·카드 축소·섹션 삽입), 신규 `src/components/PopularContentSlider.tsx`, 신규 `src/hooks/usePopularFeatures.ts`, `src/index.css`(고정 캔버스 및 가로모드 오버라이드).
- 백엔드: `page_views` 기반 집계 함수 1개 추가(읽기 전용, 기존 테이블·정책 변경 없음).
- 인기콘텐츠 매칭은 기존 `features.ts` ID 규칙을 그대로 사용하며 데이터 구조는 바꾸지 않는다.
