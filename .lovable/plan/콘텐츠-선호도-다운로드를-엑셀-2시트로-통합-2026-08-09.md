# 콘텐츠 선호도 다운로드를 엑셀 2시트로 통합

## 현재 상태
- 콘텐츠 선호도 섹션에는 다운로드 버튼이 2개(집계 CSV, 전체 기록 CSV) 있고, 각각 CSV 1장을 내려받습니다.
- 화면 표의 매장 목록은 현재 **매장명 가나다순** 상위 5개를 보여줍니다(관심수 순이 아님).
- 프로젝트에 엑셀 생성 라이브러리가 아직 없습니다.

## 목표
버튼 1개 클릭 → 시트 2개짜리 `.xlsx` 파일 1개 다운로드. 화면 수치와 100% 일치.

## 구현 방향

### 1) 엑셀 생성
- `xlsx`(SheetJS) 패키지 추가. 브라우저에서 워크북 생성 후 바이너리로 저장하므로 한글 인코딩 문제 없음.
- 파일명: `feature_reactions_summary_{YYYYMMDD}.xlsx`, MIME `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.

### 2) 시트 1 "관심수 요약"
- 화면 표를 만드는 기존 `aggregated` 집계값을 그대로 재사용(별도 쿼리·별도 계산 없음).
- 컬럼: 순위 / 제품 / 특장점 / 관심수 / 매장수 / 매장목록 / 최근 반응
- 매장목록 형식: `간석점, 강릉본점, ... +N개 매장`
- 정렬: 관심수 내림차순(현재 화면과 동일).

### 3) 매장 상위 5개 기준 정렬 변경
- 요청대로 상위 5개를 **매장별 반응 건수 내림차순**으로 바꿉니다.
- 화면과 엑셀이 달라지면 안 되므로, 집계 단계에서 매장별 건수를 함께 세고 **화면 표의 매장 칩 순서도 동일하게** 건수 내림차순으로 변경합니다(동일 건수는 매장명 가나다순).

### 4) 시트 2 "원본 데이터"
- 지금 "전체 기록 CSV"와 동일한 컬럼(기록 시각, 매장, 매장코드, 제품, 특장점, 특장점ID), 기록 시각 내림차순.
- 상단 기간/제품/매장 필터가 적용된 결과를 사용(현재 CSV와 동일 기준).

### 5) 버튼 정리
- 기존 두 버튼을 "엑셀 다운로드 (N건)" 버튼 하나로 통합.

## 확인 방법
`/admin` → 콘텐츠 선호도에서 기간을 바꿔가며 다운로드해, 시트1의 순위·관심수·매장수·매장목록이 화면 표와 일치하고 시트2 행 수가 버튼의 건수와 같은지 확인.
