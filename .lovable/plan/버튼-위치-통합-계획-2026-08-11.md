# 버튼 위치 통합 계획

## 현재 문제
홈 화면에 버튼이 3개 영역(상단 segmented control, 우측 하단 판매 인증, 하단 콘텐츠 요청)에 흩어져 있어 위치가 산만해 보임.

## 정리 방향
- **판매 인증 플로팅 버튼은 그대로 유지**.
- **콘텐츠 요청 버튼만 상단 segmented control로 이동**하여 하단의 중복 버튼을 제거.
- 제품 카드 하단은 깔끔하게 남기고, 상단에서 모든 보조 기능을 접근할 수 있게 정리.

## 구체적인 변경

### 1) 상단 segmented control에 콘텐츠 요청 버튼 추가
- 현재: 상단에 4개(지점 변경, 모바일에서 보기, 뷰킷 소개, 세로모드), 하단에 콘텐츠 요청 버튼이 있음.
- 변경:
  - 상단 segmented control에 **콘텐츠 요청 버튼**을 추가.
  - 기존 4개는 그대로 유지.
  - 하단의 콘텐츠 요청 버튼은 제거.
- 레이아웃:
  - 한 줄로 5개를 배치하되, 모바일에서는 너비가 좁으면 2줄로 자동 줄바꿈.
  - 아이콘 + 짧은 라벨 형태로 표시.

### 2) 판매 인증 플로팅 버튼은 유지
- 현재: 우측 하단에 판매 인증 플로팅 버튼.
- 변경: 위치와 형태는 그대로 두되, 상단에는 추가하지 않음.

### 3) 하단 콘텐츠 요청 버튼 제거
- 현재: 하단 가운데에 큰 pill 버튼.
- 변경: 상단 segmented control에 이동시키고 하단 버튼은 제거.

## 우선 적용안
- 상단 segmented control에 기존 4개 + 콘텐츠 요청을 포함한 5개 기능을 배치.
- 모바일(스탠바이미)에서는 너비가 좁으면 2줄로 자동 줄바꿈.
- 우측 하단 판매 인증 버튼은 그대로 유지.
- 하단 콘텐츠 요청 버튼은 제거.
- 버튼 아이콘과 라벨은 그대로 유지.
