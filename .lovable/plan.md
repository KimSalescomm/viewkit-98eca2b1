# 청소로봇 1번 특장점 헤드영역 개선

대상: `src/pages/FeatureDetail.tsx` 의 `VacuumSampleLayout` 헤드 블록(216~233행)

## 변경 내용

### 1. 흰 배경 제거
- 헤드 카드의 `bg-white` + `rounded-[14px]` + shadow 제거
- 회색 페이지 배경(`#F3F4F6`) 위에 텍스트가 바로 얹히는 형태로 변경

### 2. 헤드 / 본문 구분선 + 여백
- 헤드 하단에 얇은 구분선(`border-b border-gray-200`) 추가
- 구분선 위 여백(`pb-5 sm:pb-6`), 구분선 아래 여백(`mb-5 sm:mb-6`)으로 영상 카드와 간격 확보

### 3. 아이콘·텍스트 크기 밸런스
"붕 떠 보이는" 원인은 아이콘 박스(64px)가 텍스트 대비 크고 상단 정렬이라 여백이 남는 점이므로:
- 아이콘 박스를 `h-14 w-14`(sm `h-16 w-16`)로 조정하고 배경을 흰색 원형/라운드 대신 회색 배경 위에서 자연스러운 톤으로 정리
- 아이콘 자체 크기 `h-7 w-7` → sm `h-8 w-8`
- 정렬을 `items-start` → `items-center`로 변경해 텍스트 블록과 세로 중앙 정렬
- 텍스트 확대: 아이브로우(tag) `12px → 13px`, 타이틀 `22px → 26px`(sm `28px → 32px`), 서브카피 `14px → 15px`(sm `16px → 17px`)
- 아이콘과 텍스트 간격 `gap-4 → gap-4 sm:gap-5`

## 적용 범위
청소로봇 1번(`/product/vacuum/feature/1`) 전용 레이아웃만 수정. 다른 특장점 페이지는 그대로 유지.

## 검증
- `/product/vacuum/feature/1`에서 헤드에 흰 박스가 사라지고 구분선이 보이는지
- 아이콘이 텍스트와 시각적으로 균형을 이루는지
- 스탠바이미 세로 모드에서 레이아웃이 깨지지 않는지
