# 스탠바이미 세로 모드 컨테이너 사이즈 최적화

## 현황
- `PageContainer`가 사이트 전역에 적용되어 있음.
- 현재 폭: `max-w-xl(576px) → sm:max-w-4xl(896px) → lg:max-w-6xl(1152px)`.
- 스탠바이미 세로 모드(1080×1920)에서는 `lg` 브레이크포인트에 걸려 콘텐츠가 거의 풀브leed(약 1016px)로 펼쳐짐.
- 결과: 2열 그리드 카드가 한 장당 500px 가까이 커지고, 상단 히어로+카드가 한 화면에 들어오기 어려워짐.

## 목표
- 스탠바이미 세로 모드(9:16, 1080px 폭)에 최적화된 컨테이너 폭을 추가.
- 세로 모드에서 카드/히어로가 한 화면 내에 배치될 수 있도록 그리드와 여백도 함께 조정.
- 기존 모바일·태블릿·가로 모드(landscape) 레이아웃은 그대로 유지.

## 작업 항목

### 1. 세로 모드 전용 CSS 변수/오버라이드 추가
- `index.css`에 `html[data-orientation="portrait"]` 또는 `html:not([data-orientation="landscape"])` 미디어 쿼리 추가.
- 뷰포트 폭이 1080px 근처(예: 980px~1200px)일 때 `PageContainer`의 `max-width`를 840~920px로 제한.
- 이 폭은 9:16 세로 화면에서 2열 카드를 적당한 크기로 유지하면서도 좌우 여백을 확보함.

### 2. PageContainer 세로 모드 대응
- `PageContainer.tsx`에 세로 모드용 `data-orientation` 속성을 읽어오는 로직은 추가하지 않음(이미 `useOrientation` 훅과 `html[data-orientation]`이 존재).
- 대신 CSS에서 `.max-w-xl`, `.sm:max-w-4xl`, `.lg:max-w-6xl`에 세로 모드 오버라이드를 적용.
- 필요 시 `PAGE_CONTENT_WIDTH`를 그대로 두고, 세로 모드에서만 `max-width`를 오버라이드.

### 3. 카드 그리드 세로 모드 조정
- `VacuumFeatureGrid` 등 세로 모드에서 2열 그리드인 컴포넌트:
  - 카드 폭이 너무 커지지 않도록 `max-w` 또는 `grid` 제한.
  - 세로 모드에서 gap을 줄이고(예: gap-3), 카드 내부 폰트/이미지 비율을 조정.
- 상세 페이지(`FeatureDetail`)의 메인 미디어/갤러리도 세로 모드 폭에 맞춰 축소.

### 4. 히어로 영역 세로 모드 최적화
- `Home.tsx`의 청소로봇 샘플 히어로:
  - 세로 모드에서 높이를 제한(예: `max-h-[220px]`).
  - 제품 누끼 이미지 크기를 축소하여 카드가 위로 밀리지 않도록 조정.

### 5. 미리보기 및 검증
- 브라우저 개발자 도구에서 1080×1920 뷰포트로 확인.
- 청소로봇 목록 페이지(`/product/vacuum`)와 상세 페이지(`/product/vacuum/feature/7`) 각각 스크린샷 비교.
- 카드가 한 화면에 6~7장 정도 들어오는지, 스크롤 없이 주요 콘텐츠가 보이는지 확인.

## 기대 효과
- 스탠바이미 세로 모드에서 콘텐츠가 적당한 폭으로 중앙 정렬.
- 카드/히어로 크기가 키오스크 터치 디스턴스에 맞게 유지되면서도 한 화면 배치 가능.
- 다른 디바이스(모바일, 태블릿, PC 가로)에는 영향 없음.
