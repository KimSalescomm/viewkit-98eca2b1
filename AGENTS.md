# Project conventions

- Keep new product feature collections in focused data modules and register them in the shared features map; this preserves the existing three-level product navigation without enlarging the legacy data file.
- Store downloaded official media as immutable asset pointers and import their URLs; this keeps published product content independent of external image hosting failures.
- Render category-based air-care comparisons in a semantic row-based table with explicit per-spec advantage flags; this guarantees aligned rows without inferring superiority from differing values and preserves legacy comparisons.- Express display-only emphasis such as a recommended-product badge through optional data flags rather than product names inside shared components; this keeps one comparison renderer reusable across products.
